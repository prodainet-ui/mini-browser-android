# Мой браузер для Android

Мобильная версия «Моего браузера»: вкладки, закладки, история, загрузки, поиск по странице,
версия для ПК и своя начальная страница с погодой и курсами тенге.

**Скачать последнюю версию:** откройте раздел **Releases** справа и скачайте `MiniBrowser.apk`.

Сборка идёт автоматически в GitHub Actions после каждого изменения в ветке `main`.
Требуется Android 10 или новее.

Ключ подписи (`app/release.jks`) лежит в репозитории, чтобы обновления ставились поверх
старой версии. Это нормально для личного приложения, но не для публикации в Google Play.
